# CareCompass

CareCompass is a comprehensive healthcare navigation and patient management platform designed to simplify care coordination, appointments, and medical support.

## Features
- **Patient Navigation**: Easy access to care resources and health records.
- **Appointment Scheduling**: Seamless booking and reminder system.
- **Provider Directory**: Search and connect with healthcare professionals.
- **Care Coordination**: Secure collaboration between patients and care teams.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
npm run dev
```
